# Supermarket Sales Analysis

## Overview

This project analyzes supermarket transaction data to identify sales, product, customer, and payment trends that can help store leaders make more informed operational decisions.

## Business Question

Which products, customer segments, locations, and time periods drive sales performance, and what actions could improve operational planning?

## Tools Used

- Python
- pandas
- Jupyter Notebook / Google Colab
- Data visualization

## Analysis Process

1. Reviewed transaction-level fields and data types.
2. Cleaned and standardized dates, categories, and numeric values.
3. Created KPIs for sales, transaction volume, product performance, and customer behavior.
4. Compared results across product lines, payment methods, customer types, and time periods.
5. Summarized findings into operational recommendations.

## Skills Demonstrated

Data cleaning, KPI creation, retail sales analysis, visualization, business communication, and operational recommendations.

## Data Note

This project uses a public dataset for educational and portfolio purposes. It does not contain Walgreens data, employer information, or confidential customer information.
